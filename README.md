# C++ Demystified 🚀

**C++ Demystified** is an iOS app designed to help beginners take their first steps in C++ programming — without the overwhelm.

Learning C++ can feel intimidating at first: pointers, memory management, syntax... it's a lot. This app breaks it all down into clear, bite-sized lessons that make the language approachable and actually enjoyable to learn.

## What the app offers

- 📖 **Structured lessons** — concepts introduced progressively, from the very basics to more advanced topics
- 💡 **Simple explanations** — no unnecessary jargon, just clear language that makes sense
- ✅ **Quizzes & exercises** — to reinforce what you've learned and track your progress
- 📱 **Native iOS experience** — built entirely in Swift, for a smooth and intuitive interface

## Who is it for?

Anyone who wants to learn C++ from scratch — students, curious minds, or developers coming from another language who want to add C++ to their toolkit.

## Tech stack

- **Language:** Swift
- **Platform:** iOS
